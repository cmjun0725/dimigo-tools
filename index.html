🔍 기본 검색

검색창에 모르는 단어를 입력하면 AI가 즉시 분석합니다. 예: 진대법, 뷰렛반응, 이차방정식, 비유

🏷️ 과목 필터

상단의 과목 탭을 누르면 해당 분야만 검색할 수 있습니다. 역사를 선택하면 타임라인도 함께 표시됩니다.

📅 타임라인

역사 용어를 검색하면 한국사 타임라인에 해당 시기가 표시됩니다. 구석기부터 현대까지 확대/축소 가능!

⚙️ API 키 설정

우측 상단 ⚙️를 눌러 OpenRouter API 키를 입력하세요. 키가 있어야 AI 분석이 작동합니다.

💬 댓글 분석기 사용법
🔗 링크 입력

YouTube 영상 URL을 복사해서 붙여넣으세요. youtube.com/watch?v=... 형식이면 됩니다.

📊 AI 감정 분석

AI가 댓글을 분석해서 긍정/부정/중립/질문/제안 등으로 분류합니다. 각 카테고리를 누르면 상세 댓글 확인!

🎬 영상 정보

영상 제목, 채널명, 조회수, 좋아요수, 댓글수 등 기본 정보도 함께 표시됩니다.

🔑 API 키 필요

YouTube Data API 키와 OpenRouter API 키가 모두 필요합니다. ⚙️ 설정에서 입력하세요.

❓ 자주 묻는 질문
API 키는 어떻게 발급하나요?
OpenRouter: openrouter.ai/keys에서 무료로 발급 가능 (소량 사용 시 무료)
YouTube: Google Cloud Console에서 YouTube Data API v3 키 발급
데이터가 저장되나요?
아니요. 모든 데이터는 브라우저의 localStorage에만 저장됩니다. 서버에 어떤 데이터도 저장되지 않으며, API 키도 브라우저 안에서만 관리됩니다.
모바일에서도 사용할 수 있나요?
네! 모바일 브라우저에서도 완벽하게 작동합니다. 반응형 디자인이 적용되어 있어 화면 크기에 맞게 자동 조정됩니다.
댓글 분석에 시간이 얼마나 걸리나요?
댓글 수에 따라 다르지만, 보통 10~30개의 댓글 분석에 5~15초 정도 소요됩니다. 200개까지 수집 가능합니다.
