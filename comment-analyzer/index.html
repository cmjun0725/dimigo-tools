AI 기반 실시간 분석

댓글 분석기

YouTube 영상 링크를 붙여넣으면 AI가 댓글의 감정과 반응을 나뭇가지처럼 분석해 드립니다

⚙️ 버튼에서 OpenRouter API 키를 설정해주세요

📖 사용법

1️⃣ 링크 입력
YouTube 영상 URL을 복사해서 붙여넣으세요
2️⃣ AI 분석
AI가 영상을 분석하여 나뭇가지 형태로 분류합니다
3️⃣ 가지 확장
카테고리 → 세부분류 → 댓글 순으로 클릭하여 확장
🔑 API 키
⚙️에서 OpenRouter 키 입력 (openrouter.ai/keys)

분석을 시작합니다...
