댓글 분석기

YouTube 영상 링크를 붙여넣으면 AI가 댓글을 나뭇가지처럼 분석해 드립니다

⚙ 버튼에서 OpenRouter API 키를 설정해주세요

📖 사용법

1. 링크 입력
YouTube 영상 URL을 복사해서 붙여넣으세요
2. AI 분석
AI가 영상을 분석하여 나뭇가지 형태로 분류합니다
3. 가지 확장
카테고리 클릭 → 세부분류 클릭 → 댓글 확인
4. API 키
⚙에서 OpenRouter 키 입력 (openrouter.ai/keys)

분석을 시작합니다...
