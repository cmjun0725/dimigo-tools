AI 기반 실시간 분석

댓글 분석기

YouTube 영상 링크를 붙여넣으면 AI가 댓글의 감정과 반응을 분석해 드립니다

⚙️ 버튼에서 OpenRouter API 키를 설정해주세요

📖 사용법

1️⃣ 링크 입력
YouTube 영상 URL을 복사해서 붙여넣으세요
youtube.com/watch?v=...
2️⃣ AI 분석
AI가 영상 링크를 분석하여
감정별·주제별로 분류합니다
3️⃣ 상세 확인
각 카테고리를 클릭하면
상세 내용과 댓글 예시 확인
🔑 API 키 필요
⚙️ 설정에서 OpenRouter 키 입력
openrouter.ai/keys

분석을 시작합니다...

⚙️ API 설정

OpenRouter에서 발급 (openrouter.ai/keys)
